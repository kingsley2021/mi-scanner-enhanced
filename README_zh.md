# Mi Scanner Enhanced

修复小米扫一扫（小爱视觉/AI扫描）中两个问题的 LSPosed 模块。

[English](README.md)

## 修复内容

**文本扫描结果被审查屏蔽。** 小米扫一扫会将文本类扫描结果发送到远程服务器进行内容审核。如果内容被标记、请求失败或没有网络连接，结果会被隐藏并从扫描历史中删除。本模块移除了服务器审核，扫描结果直接显示。

**扫描 WiFi 二维码需要位置权限。** 扫描 WiFi 二维码后，应用要求授予位置权限才能连接网络。实际的连接过程并不需要位置权限。本模块跳过位置权限检查，其他权限（如相机）不受影响。

## 安装

1. 从 [Releases](../../releases) 页面下载 APK 并安装。
2. 在 LSPosed 中启用模块，确认扫一扫已勾选为目标应用。
3. 打开扫一扫即可生效。

## 兼容性

在 15.9.77 版本上测试通过。其他版本应该同样可用。如果更新后模块失效，请[提交 issue](../../issues)。
